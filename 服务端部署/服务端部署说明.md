# 服务端部署说明 · iperf3（银河麒麟 V10 / 统信 / 其他 Linux）

> 用途：在服务器上常驻运行 iperf3 服务端，供客户端的**快速检测**（带宽测试）与**长期监测**（TCP/HTTP 探测）使用。
> 适用服务器：192.168.67.133（麒麟 V10 ARM）或任意 Linux 服务器。
> 对应端口关系：**用户客户端 → 外网 59.211.236.211:30014 → NAT 映射 → 内网服务器 5201（iperf3 监听）**

---

## 一、目录文件说明

```
服务端部署/
├── 启动服务端.sh        # 一键部署：定位 iperf3 + 生成 systemd 服务 + 开机自启 + 验证
├── 停止服务端.sh        # 一键停止 + 取消开机自启
├── iperf3-server.service  # systemd 服务文件（模板，路径按需修改）
└── 服务端部署说明.md    # 本文档
```

---

## 二、第一步：编译/准备 iperf3（只做一次）

麒麟 ARM 机器上用源码包编译（工具包 `源码包/iperf-3.14.tar.gz`）：

```bash
# 1. 安装编译工具（如已安装可跳过）
sudo yum install -y gcc make

# 2. 解压编译
tar -zxf iperf-3.14.tar.gz
cd iperf-3.14
./configure --disable-shared
make -j$(nproc)
sudo make install          # 安装到 /usr/local/bin/iperf3（推荐）

# 3. 验证
iperf3 --version
```

> 不想 `make install` 也可以，脚本会自动在 `/usr/local/bin`、`/usr/bin`、`/opt/iperf-3.14/src` 中查找。

---

## 三、第二步：一键部署（推荐）

```bash
cd 服务端部署
sudo bash 启动服务端.sh          # 默认端口 5201
# 或指定其他端口：sudo bash 启动服务端.sh 9527
```

脚本自动完成：
1. 定位 iperf3 可执行文件
2. 生成 `/etc/systemd/system/iperf3-server.service`（含开机自启）
3. `systemctl enable --now iperf3-server` 启动
4. 验证监听状态并打印部署信息

**验证监听：**

```bash
ss -tlnp | grep 5201
# 期望输出: LISTEN  0  128  0.0.0.0:5201  ...  (iperf3)
```

**查看日志：**

```bash
journalctl -u iperf3-server -f     # 实时日志
tail -f /var/log/iperf3_server.log # 或服务日志文件
```

---

## 四、第三步：防火墙放行

麒麟默认防火墙可能拦截 5201：

```bash
# firewalld 方式
sudo firewall-cmd --permanent --add-port=5201/tcp
sudo firewall-cmd --reload

# 或 iptables 方式（如未用 firewalld）
sudo iptables -I INPUT -p tcp --dport 5201 -j ACCEPT
```

---

## 五、第四步：确认 NAT 端口映射（关键！）

网关/NAT 设备上必须配置：

```
公网（客户端访问）:  59.211.236.211 : 30014
                     ↓ 端口映射
内网（iperf3 服务）:  192.168.67.133 : 5201
```

客户端工具 `config.ini` 中配置对应：

```ini
[目标]
外网映射地址 = 59.211.236.211
外网映射端口 = 30014
内网真实地址 = 192.168.67.133
内网真实端口 = 5201
```

> ⚠️ 若 NAT 映射端口变更，必须同步修改网关配置和客户端 config.ini。

---

## 六、停止 / 卸载

```bash
cd 服务端部署
sudo bash 停止服务端.sh        # 停止 + 取消开机自启
```

如需彻底卸载：删除 `/etc/systemd/system/iperf3-server.service` 后 `systemctl daemon-reload`。

## 七、常见问题

| 现象 | 排查 |
|---|---|
| 脚本报"未找到 iperf3" | 按第二节编译；或编辑 `启动服务端.sh` 顶部 IPERF3 路径 |
| 服务启动失败 | `journalctl -u iperf3-server -n 50` 看报错；多为端口占用，先 `ss -tlnp \| grep 5201` |
| 端口被占 | 换端口（脚本带参数）或释放占用：`sudo fuser -k 5201/tcp` |
| 客户端 TCP 探测不通 | ① 服务是否运行 ② 防火墙 ③ NAT 映射 ④ 外网地址是否可达 |
| 客户端带宽测试通但 Ping 不通 | 正常！服务器禁 ping（ICMP），工具已自动识别跳过 |
| 服务器重启后服务没了 | 未成功 enable；`systemctl is-enabled iperf3-server` 检查 |

## 八、与客户端工具的配合说明

- **长期监测**：周期性 Ping + TCP + HTTP 探测，**不需要跑带宽**；但 TCP 探测的目标端口必须有服务监听（本 iperf3 服务即可）
- **快速检测**：会跑 iperf3 带宽测试（单流 / 并行 / 反向），服务端无需额外操作，收到连接自动响应
- iperf3 服务端**支持多客户端同时测试**，无并发限制问题
