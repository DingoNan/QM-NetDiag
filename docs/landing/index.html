"系统连不上、访问好慢"
——问题到底出在哪？

一体化系统断连、卡顿、时断时续，是最常见也最难说清的问题。一线用户说不清，运维到场才发现是 DNS、是出口、还是服务端。

说不清症状

"打不开系统"背后可能是丢包、断连、DNS 解析失败或服务端宕机。靠人描述，运维只能猜。

常见问题

你可能想问

需要安装 Python 或任何依赖吗？

不需要。分发的是绿色免安装包，已内置 iperf3 二进制，拷贝到目标机器双击即可运行。源码运行也只需系统自带 Python 3.8+（麒麟需安装 python3-tkinter）。

工具会上传我的数据吗？

不会。所有测试在本机执行、报告在本机生成，工具本身没有任何上传行为，测试目标地址也可在配置中完全自定义。适合政务网等敏感内网环境。

杀毒软件提示拦截怎么办？

PyInstaller 打包的程序可能被 360 / 火绒等提示，这是常见误报。项目采用 onedir 模式打包以降低误报率，添加信任 / 白名单即可正常使用。

麒麟系统上怎么运行？

使用麒麟 x64 或麒麟 ARM 绿色包（鲲鹏 / 飞腾对应 ARM 版）。如提示缺少 tkinter，执行 yum install -y python3-tkinter 即可。启动时工具会自动识别系统与架构。

iperf3 测试报失败怎么办？

确认目标服务器已运行 iperf3 -s，且 NAT 映射端口正确。iperf3 服务器地址可在设置中单独配置，测试目标也可完全自定义。

长期监测什么时候会用到？

专治"时断时续"类间歇性故障：快速检测没问题但系统就是时不时卡一下时，开启 10 分钟长期监测，工具会自动记录丢包、断连、延迟突增事件，生成趋势图与事件时间线，把"说不清"变成"几点几分发生了什么"。
