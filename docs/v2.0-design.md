## 一、愿景与目标用户

### 1.1 一句话定位

> **v1 是给运维人员用的「工业 CT 机」，v2 是给普通人用的「智能手表」。**

| 维度 | v1（当前）| v2（本次）|
|---|---|---|
| **目标用户** | 政企内网 IT 运维、信创集成商 | 游戏玩家、视频博主、远程办公、跨境电商、白嫖党 |
| **使用场景** | 排查专线故障、做合规报告 | 看看游戏卡不卡、视频加载快不快、能不能访问 ChatGPT |
| **典型问题** | "信创环境下一体化系统到某节点的丢包率是多少？" | "我新买的路由器玩 LOL 延迟多少？" |
| **审美取向** | 政务蓝、表格密集、严肃 | 暗色 + 霓虹、图形化、酷炫 |
| **上手成本** | 需要懂网络术语 | 一键开测 |
| **结果呈现** | HTML 报告（合规存档）| 仪表盘 + 可分享卡片 |

### 1.2 目标用户画像

| Persona | 典型场景 | 痛点 |
|---|---|---|
| **🎮 游戏玩家"小张"** | 玩 LOL/原神/Steam，看延迟多少能上分 | 想知道"我家宽带到腾讯服务器到底快不快" |
| **📹 UP主"小李"** | 录 4K 视频上传 B站 | 想知道"现在上传速度快不快，能不能赶在中午发" |
| **💼 远程办公"小王"** | 海外办公，连接 Zoom/Slack | 想知道"今天到美国的延迟是不是正常" |
| **🛒 海淘党"小陈"** | 经常登录 Google/ChatGPT | 想知道"我的科学上网节点还活着吗" |
| **🧑‍💻 开发者"小赵"** | 经常 GitHub/Git clone | 想知道"GitHub 现在能不能 pull" |

## 二、核心差异化设计

### 2.1 v1 → v2 的根本转变

**v1 思维**：列出 5 项测试，用户自己看结果。
**v2 思维**：用户只问"卡不卡"，工具直接告诉他"卡 / 流畅 / 一般" + 原因 + 建议。

### 2.2 三大核心特性

#### ✨ 特性 A：预置网站库（即开即用）

**v1**：用户必须自己填 IP/端口（普通用户根本不懂）
**v2**：内置 100+ 常用网站，按场景分类，一键选择

```
🎮 游戏    ▶️ 腾讯游戏 / 网易 / Steam / Epic / 暴雪 / Riot / PSN
🎬 视频    ▶️ B站 / 优酷 / 爱奇艺 / YouTube / Netflix / Twitch
💬 通讯    ▶️ 微信 / QQ / 钉钉 / 企微 / Discord / Telegram / Zoom / Teams
👨‍💻 开发   ▶️ GitHub / GitLab / Stack Overflow / npm / PyPI / ChatGPT
🌐 社交    ▶️ 微博 / 知乎 / 小红书 / Twitter / Facebook / Instagram
🛒 购物    ▶️ 淘宝 / 京东 / 拼多多 / 亚马逊 / 1688
📚 知识    ▶️ 百度 / 维基 / 掘金 / CSDN
🌍 海外    ◀ Google / Cloudflare / AWS / Azure / Apple
```

#### ✨ 特性 B：可视化诊断（图形化）

**v1**：返回"平均延迟 35ms，丢包 0%"
**v2**：返回：
- 速度计：`35 ms`（绿/黄/红三色自动判定）
- 雷达图：同时对比 5 个目标
- 抖动波形：测速过程的实时曲线
- 评分：A+/A/B/C/D 五档，给出"流畅/一般/卡顿"评语

#### ✨ 特性 C：分享卡片（社交属性）

**v1**：HTML 报告，截图给运维看
**v2**：一键生成"测试海报"：
- 顶部：用户头像 + 网速大数字
- 中部：彩色仪表盘
- 底部：测试时间 + 二维码（扫码重测）
- 可直接发到微信群/朋友圈

## 三、UI/UX 设计规范

### 3.1 设计语言：赛博朋克 + 现代极简

**核心原则**：
- **暗色优先**（个人用户偏好，护眼）
- **霓虹强调色**（青、蓝、紫渐变）
- **大量留白**（不让用户视觉疲劳）
- **图形优先**（一个仪表盘胜过十行表格）

## 七、评分系统设计

### 7.1 评分算法

```python
def calculate_score(metrics: dict) -> tuple:
    """
    返回 (score, grade, label, color)
    score: 0-100 数字
    grade: A+/A/B/C/D
    label: 评语
    color: 颜色
    """
    latency = metrics.get('avg_latency_ms', 999)
    jitter = metrics.get('jitter_ms', 0)
    loss = metrics.get('loss_pct', 100)

    # 综合评分（延迟权重 60%，抖动 25%，丢包 15%）
    latency_score = max(0, 100 - latency * 1.5)  # 100ms = -150
    jitter_score = max(0, 100 - jitter * 5)
    loss_score = max(0, 100 - loss * 10)

    score = latency_score * 0.6 + jitter_score * 0.25 + loss_score * 0.15

    if score >= 90:   return (score, 'A+', '流畅丝滑 🚀', 'status-good')
    elif score >= 75: return (score, 'A',  '流畅', 'status-good')
    elif score >= 60: return (score, 'B',  '一般', 'status-warn')
    elif score >= 40: return (score, 'C',  '略卡', 'status-warn')
    else:             return (score, 'D',  '卡顿', 'status-bad')
```

### 7.2 评语生成（自然语言）

```python
def generate_comment(metrics: dict) -> str:
    latency = metrics['avg_latency_ms']
    loss = metrics['loss_pct']

    if latency < 30 and loss == 0:
        return "网络状态优秀，玩游戏毫无压力"
    elif latency < 60 and loss == 0:
        return "网络流畅，日常使用完全够用"
    elif latency < 100 and loss < 1:
        return "网络一般，部分场景可能略有卡顿"
    elif loss > 5:
        return "检测到明显丢包，建议检查网络或重启路由器"
    elif latency > 200:
        return "延迟较高，跨国访问或运营商线路繁忙"
    else:
        return "网络状态不佳，建议联系运营商"
```

## 十、风险与挑战

| 风险 | 应对 |
|---|---|
| 预置网站 IP/域名变动 | 每季度更新 targets.py；标记"可能失效" |
| 国外网站测试慢/超时 | 设超时上限（5 秒），失败标黄不标红 |
| 个人用户隐私 | 默认不上传任何数据；历史记录仅本地 |
| 玩家想测"自己服务器" | 提供"自定义目标"入口 |
| 误用为黑客工具 | 不做端口扫描、不做漏洞探测，只做连通性 |
| 美工能力受限 | 引入设计 token 系统；参考成熟组件库；减少自定义设计 |

## 十二、为什么 v2 一定能做得好看

v1 我承认做得"功能正确但审美平庸"。v2 我会做以下根本性改变：

### 12.1 不再从零设计

- ✅ **采用设计 token 系统**：颜色、字号、间距、圆角、阴影全部规范化
- ✅ **参考成熟产品**：Fluent UI 2、Material You、Arc Browser、Linear、Raycast 的设计语言
- ✅ **使用现成组件库风格**：toga（如果有）或自建但参照 Material

### 12.2 图形优先于文字

- ✅ 一个**速度计**胜过 10 行 "平均延迟 35ms"
- ✅ 一个**雷达图**胜过 5 个 "目标: LOL/B站/微信/Steam/GitHub"
- ✅ 一个**波形图**胜过 "抖动 1.2ms，最大 5ms，最小 0.8ms"

### 12.3 暗色 + 大量留白

- ✅ 主背景 `#0A0E1A`（深邃夜空）配 `#E8ECF4` 主文本
- ✅ 卡片之间 24-32px 间距（不是 8px 拥挤）
- ✅ 关键数字 48-64px（不是 13px 缩在角落）

### 12.4 微交互

- ✅ 按钮 hover：阴影+发光增强
- ✅ 数字滚动动画（5 秒从 0 到 87）
- ✅ 速度计指针平滑转动
- ✅ 测试进度：环形进度 + 实时百分比
- ✅ 加载骨架屏（不是白屏等待）

### 12.5 诚实的设计取舍

- 我**承认**：没有专业设计师参与，做不到 TRAE 那种精致
- 我**承诺**：v2 至少达到 **Notion / Linear / Arc Browser** 的水平
- 我**不假装**：配色、布局会参考成熟产品，不追求"独创美学"
